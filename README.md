# Clover House Arcade

Download and extract the repository ZIP, then double-click **Play.html**. All three games run offline in a modern desktop browser.

Three mouse-controlled minigames share a session score. In Orchard, click connected groups of matching fruit to feed the bird. Shuffle for a fresh board. In Twenty One, hit or stand against a dealer who stands on 17. In Color Wheel, stop the numbered wheel when the target color reaches the pointer.

With Python 3.11 or 3.12 and a graphical desktop, run:

```sh
python -m pip install -r requirements.txt
python game.py
```
