# Clover House Arcade

Download and extract the repository ZIP, then double-click **Play.html**. All three games run offline in a modern desktop browser.

The browser games share a session score. Drop an orchard and spot the longest matching fruit trail for +3 points. A miss costs up to 2 points. Choose Just watch to skip the challenge. Birds hop along one trail at a time before gravity refills the gaps. In Twenty One, hit or stand against a dealer who stands on 17. In Color Wheel, choose a pocket or group and watch the wheel settle on its own.

To play the original Pygame edition on a graphical desktop with Python 3.11 or 3.12, run:

```sh
python -m pip install -r requirements.txt
python game.py
```
